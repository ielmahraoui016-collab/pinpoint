# Pinpoint

Pin the moments that matter in any video, with titles, glowing dots on the bar and one-click jump-back.

Press **P** or click the pin button, give the moment a title, and a glowing dot appears on the progress bar. Hover a dot to see its title, or click it to jump straight back. A pin list shows all your pins for that video. It works on YouTube and on any site with a video.

## What is Pinpoint?

Pinpoint is a Chrome extension that lets you pin any moment in any video.

## Where it's useful

Personally, it helped me a lot when I'm studying on YouTube and want to pin a moment so I can get back to it. I searched for an extension that could do this and didn't find one, so I hope it helps someone else too.

## How to install

1. Download the files: [**Download Pinpoint (ZIP)**](https://github.com/ielmahraoui016-collab/pinpoint/archive/refs/heads/main.zip)
2. Unzip it. You'll get a folder with the files inside. Don't change the file names or format.
3. Go to your browser's extensions page (`chrome://extensions`, or `brave://extensions` in Brave).
4. Turn on **Developer mode**.
5. Click **Load unpacked** and select the unzipped folder.
6. You're good to go, enjoy!

## Shortcut

| Key | Action |
| --- | ------ |
| **P** | Pin the current moment |
