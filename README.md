# pinpoint
Pinpoint pins the exact moments you care about in any online video. Press P or click the pin button, give the moment a title, and a glowing dot appears on the progress bar. Hover a dot to see its title, or click it to jump straight back. A pin list shows all your pins for that video. It works on YouTube and on any site with a video.
What is PinPoint:
so basically what pinpoint is a chrome extension that makes you able to pin any moment in any video
Where it's usefull:
personally it helped me a lot when i'm studying in youtube and i want to pin a moment to get back to it, i searched for any extension that can do this but i didn't find so i hope i help someone with this
